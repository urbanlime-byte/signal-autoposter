signal auto poster

posts ur ad in ur signal groups every hour on its own. ur pc gets linked to ur signal like signal desktop does

how to use

1. unzip the folder somewhere it can stay like C:\SignalAutoPoster, dont leave it in downloads
2. double click "Signal Auto Poster" and the app opens
3. click Setup. it checks java and grabs everything it needs. if it installs java close the app and open it again
4. click Link phone. a qr code opens in ur browser, on ur phone go signal > settings > linked devices > + and scan it
5. ur groups show up on the left, tick the ones u want ads in
6. write ur ad in the box, emojis are fine. want a pic with it hit Pick
7. hit Post once now to test it, check ur groups
8. hit START and leave the app open, u can minimize it. hit STOP or close it to stop

stuff to know

- everything saves on its own, next time u open it ur groups and ad are still there
- u can change the ad or groups while its running, next round uses the new one
- joined a new group? hit Refresh groups and tick it
- the box at the bottom shows what its doing, if a group fails it says why (also saved in autoposter.log)
- pc has to stay on, sleep mode stops it (settings > system > power > sleep: never)
- want it to start with windows? win+r, type shell:startup, hit enter, put a shortcut to "Signal Auto Poster" in there, then just hit START
- if it says ur pc got unlinked just click Link phone again
- signal bans accounts that get reported for spam so only post in groups that allow ads
